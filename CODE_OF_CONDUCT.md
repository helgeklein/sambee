# Code of Conduct

This project is a shared space for users and contributors worldwide. By participating, you agree to the following rules.

## Expectations

- Write in English so the whole community can participate and benefit.
- Be friendly, respectful, and professional. Disagree with ideas constructively; do not insult, belittle, threaten, or make dismissive or hostile comments.
- Keep reports and discussions focused on the project. Describe problems and criticism clearly, specifically, and without blame.
- Format posts for readability. Paste logs as text in fenced code blocks, include only relevant lines, and do not use screenshots for log output.

## Enforcement

Maintainers may edit, hide, lock, or remove content that does not follow these rules, and may limit participation for repeated or serious violations.
